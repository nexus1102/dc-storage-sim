## 1. 验收规则

1. 每次正式验收冻结标准编号、版次、修订/勘误、项目地点、供电制式、设施等级、设备类型及适用范围。历史版与当前版分开，不能无说明混用。国外标准、指南、团标是否被项目采用，应明确记录，不一概表述成中国强制法规。
2. 建立逐条链路：标准及准确条款 → 经审阅的要求/阈值/单位 → 模型约束或外部工程要求 → 参数证据 → 独立测试 → 对应运行及源码哈希 → 差距与审阅结论。目录页只支持名称/状态/范围，不能代替条款全文。
3. 状态限定为待核验、待实现、待测试、模型层通过、外部证据通过、不适用、失败。缺少证据不能默认通过；不适用必须说明适用性理由并由责任人审阅，不能用来回避用户指定的规范。
4. 区分软件验收、模型条款验证、实测校准、工程符合性及第三方认证。只允许声明证据覆盖的范围。对接地、防火、保护、毫秒级切换等当前优化模型无法证明的要求，列为外部证据必需项。
5. 标准差距不通过放松备用/SLA、覆盖旧基线或删除冷却负荷解决。标准要求与既有假设冲突时，保留旧口径回归，另建带适用性说明的新模式和基线。
6. 正式交付必须附标准差距报告；存在待核验、失败或缺少外部证据的适用条款时，标准符合性保持BLOCKED。可以完成软件工作包，但不得写成“全部规范验收通过”。

## 3. 模型、独立测试与证据交付

以下是下一轮开发/验收的任务定义，尚未执行，亦非声称所有要求来自某一条标准。

| 工作包 | 对应ID / 模型入口 | 独立验收要求 | 附加证据 |
|---|---|---|---|
| S1 可靠性指标与故障域 | STD-01/06/07/08；`sim/reliability.py`、`physical_topology.py` | 分离给定失电事件下的EENS、事件概率、年化风险及备用轨迹达标率；功率和电量约束作用于同一交付量，不能重复累计缺额；单元/路径/维护/共同原因按不同事件建模 | 故障频率、条件分布、修复及维护数据、置信区间；无频率数据不输出未经说明的MWh/年 |
| S2 备用与转供时间线 | STD-02/03/06/07/08；`physical_topology.py`及新增事件回放 | 从失电、检测、切换、柴油机启动、带载到恢复逐段回放；失败及维护退出有反例；不能用15分钟步长证明毫秒级不中断 | 实站单线图、ATS/STS/UPS及柴油机测试、保护配合、接地资料；相应工程项保持外部证据待验 |
| S3 电池与激活能量闭合 | STD-03/09/10；`dispatch.py`、`degradation.py`、`tools/battery_degradation.py` | 统一交流/直流计量、SOC、SOH、倍率/温度降额与退化单位；验收P0完整循环反例、零偏/有偏AGC以及备用后再充电恢复 | 化学体系、BMS边界、厂家放电曲线、充电策略及设备试验；不存在一种“通用浮充”强加所有体系 |
| S4 并网与调频接口 | STD-04/10；`dispatch.py`、`stochastic.py`及外部动态模型 | 容量投标、调度履约、设备动态响应和市场资格分别验收；共享投标样本外验证；保护动作与孤岛模式不等同备用SOC | 适用电网/频率、并网协议、动态试验和市场规则；毫秒响应需更细模型或硬件试验 |
| S5 能效与服务边界 | STD-05/11；热模型、`service_contracts.py`及报告 | PUE类统计固定设施/IT计量边界；增加配电/UPS损耗和必要附属用电，避免仅IT+空调冒充完整设施；MLC/ELC按核定版次另算；冷却服务不因对照开关消失 | 年度工况、气象、设备部分负载曲线、计量点；业务SLA另证，不能由基础设施标准反向保证 |

现有`sim/reliability.py`每次抽样对应一次给定失电事件，其`EENS_MWh`是该抽样分布下的事件条件均值。模块头部仍有“MWh/日”及旧缺额加法说明，与当前实现口径有差异，应在S1中统一说明、输出字段与独立测试；不能沿用为已核准标准指标。备用轨迹达标率也不等于设施可用率，零次失效的有限样本不能证明失效概率为零。

测试证据至少记录：要求ID、版次/条款、对象与单位、阈值来源、输入版本、测试代码、执行命令、运行路径、源码及输入哈希、结果、适用性边界、审阅人。运行产物放`runs/`/`results/`，Git只管理要求、代码和精简结论，不提交运行目录或标准全文。

## 4. 后续验收报告必须使用的结论格式

| 层次 | 本轮状态 | 允许的结论 |
|---|---|---|
| 需求覆盖 | 已登记11项 | 11项已进入规范核对清单 |
| 标准身份与条款取证 | 部分完成 | 官方元数据/范围初核；具体条款与适用性仍有缺口 |
| 模型条款验证 | 待开展 | 不得写“全部标准通过” |
| 工程与设备符合性 | 待外部证据 | 不得写现场设计、UPS动态性能或接地合规已通过 |
| Tier等第三方认证 | 未认证 | 不得用模块数、软件结果或本矩阵代替认证 |

正式验收结论同时列软件状态、模型条款状态和外部证据状态。标准相关的总状态为BLOCKED，直至适用条款有完整审阅与验证链路；本矩阵本身不构成工程合规证书。
