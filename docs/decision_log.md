# 建模决策日志

| 日期 | 选择 | 原因和证据 | 边界 |
|---|---|---|---|

| 2026-11-10 | 官方历史2025-06电价 | 国网代理购电价可溯源；426号自2025-06-01执行 | 不是2026现货预测 |
| 2026-11-10 | 容量价0；里程和AGC参数为假设 | 监管公告确认新调频规则于2026-05-01施行；未取得当期结算数据 | W0.1真实辅助服务标定仍需外部证据 |
| 2026-11-10 | 相邻段二进制实现SOS2，插值总成本 | HiGHS无原生SOS2；吞吐乘单位成本会双线性 | 日等效深度代理；调频单独按浅循环档；未做雨流计数 |
| 2026-11-10 | 热平衡精确离散 | C*dT/dt=UA*(Tamb-T)+IT-COP*AC；e=(Tmax-T)/温差 | 热参数未实测；冷却通过负荷/备用改变电池调频域 |
| 2026-11-10 | 圆周备用窗口与分数时隙 | 末状态面对下一时段负荷；与循环SOC一致 | CVaR为等效尾时长代理；worst臂按全穿越时长 |
| 2026-11-10 | 有限设计值函数+MILP主问题 | 每个整数候选用完整运行约束；等价于有限设计析取模型 | 仅5–64模块设计域；触界须报告 |
| 2026-11-10 | ε约束重新调度，词典序最小EENS | 筛选原成本最优调度会遗漏可靠性改进 | 五个标准架构；不用NSGA-II |
| 2026-11-10 | 更换费用替代吞吐代理费 | 防止重复计入磨损；SOH降低后逐年重新调度 | 代表日重复365次；线性日历/EFC衰减 |
| 2026-11-10 | 日前变量共享对象；DRO内生对偶 | 单场景锚点和非预见性检查 | 二阶段完整揭示；L1半径不是总变差半径 |
| 2026-11-10 | 四范式固定同组OOS | 禁止各用最优分布；训练评价seed分离 | 合成乘数分布；不代表经验市场频率 |
| 2026-11-10 | 供能=min(SOC效率;功率×时间) | 修复双约束同时紧时的失供重复计算 | 条件于一次失电，未虚构年度故障频率 |
| 2026-11-10 | MPC固定业务服务率并携带截止历史 | 滚动预测窗口均值不应改变物理恢复能力 | 备用、SOC终端和热终端松弛显式计费 |
| 2026-11-10 | 每轮重置HiGHS全局调度器，固定1线程 | PyPSA默认线程与新内核线程不一致导致status unknown | 同进程顺序求解；各实验独立进程 |
