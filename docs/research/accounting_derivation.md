# 能量与计费修订的独立推导

2026-11-11。依据用户提供论文式(23)、(28)所提示的完整吞吐及效率损失机制，结合本项目标定分母重建。论文不是本站电池参数或标准限值来源。

## 完整循环反例

额定E=1 MWh，一个深度d=0.3的理想循环完整交流侧吞吐Q=0.6 MWh，半吞吐H=0.3 MWh。若造价800000元/MWh、每循环衰减0.0001，损失80元。标定单价r=800000×0.0001/(2×0.3)=133.333333元/完整吞吐MWh；rQ=80，而rH=40，后者少计一半。

修正曲线横坐标仍为H/E，纵坐标由d×r(d)改为2d×r(d)。在折点之间插值总成本，不将插值单价与变量深度相乘。浅循环及固定单价模式同样换算；AGC成本按完整实际激活吞吐计价。每日等效深度是代理，并非雨流循环深度。标定的完整吞吐按名义循环能量近似，未将电压曲线、温度或AC/DC损耗重新标定，不冒称精确电化学寿命。

## AGC及电表闭合

对每时段容量Rup、Rdn，a_up/a_dn为该时段单向满功率等效激活时间比例，均非负且合计不大于1。Ec=dt×a_dn×Rdn，Ed=dt×a_up×Rup，单位MWh。默认各0.05是合成情景；可提供逐时非对称轨迹。

SOC_end=SOC_start+dt×(eta×Pch-Pdis/eta)+eta×Ec-Ed/eta。

G_meter=G_schedule+Ec/dt-Ed/dt，G_schedule=Psite+Pch-Pdis。购电和需量用G_meter，完整吞吐Q=dt×Σ(Pch+Pdis)+Σ(Ec+Ed)。调频收益用容量合同，不能用激活电量重复结算容量收入。

交流侧各充、放1 MWh，eta=0.95时SOC损失1/0.95-0.95=0.1026315789 MWh；eta=1时为0。单向上调SOC变化为-Ed/eta，下调为eta×Ec。周期日必须由计划充电补回损失，购电也随之增加。

正常计划充放电互斥采用二进制；同一时段的双向AGC表示细时间尺度上的先后激活，不是同时充放电。上/下调容量仍须分别满足瞬时功率、SOC余量和不反送/进口上限。逐单元SOC采用相同激活比例，总和应与站点闭合；这是给定激活轨迹的离线评价，不是秒级动态认证或对未知所有激活轨迹的鲁棒保证。

进一步采用保守的全站协调策略：一个时段只选择计划充电、计划放电或调频；调频时段计划充放电为零，计划循环时段上下调容量为零。因此激活电量不会与同一设备的反向计划电量叠加。它限制了可行域，不能声称给出了允许分组并行或更细时间调度下的全局最大能力/收益。AGC时段内部上下调可以先后发生，均值轨迹及能量裕度仍是给定调用的近似，不代替秒级回放。

固定事前投标在持续单向调用下可能无法满足循环日SOC。样本外评价明确返回feasible=false、成本和未定义风险值为NaN，不重拟投标或编造有限成本。汇总时必须保留不可行样本的数量与比例，不能直接dropna后声称所有情景均可执行。
