# 博士课题的论文分析与结论边界

日期：2026-11-11。研究对象：既有IDC/AIDC中，不同业务约束与N、N+1、2N+1、2(N+1)架构下电化学储能的闲置调度能力。**现阶段可以形成模型与机制分析论文；尚不能形成目标站点完成实证校准、工程规范全部符合或真实AI服务保证的结论。** 本轮没有新增模型功能、重跑大型实验或改变参数基线。

## 1. 对用户所给论文的承接

肇嘉毅等的实体—虚拟储能耦合论文支持“业务与冷却调整改变备用需求”的机制解释，但其20 MWh/10 MW园区储能、45分钟备用、CPU业务和历史价格不直接代表已有UPS或GPU业务。原文身份、页码、公式疑点及SHA已记录在[原文评审](../paper_reviews/zhao_2026_physical_virtual_storage.md)。

本项目已经完成完整吞吐计费、AGC能量闭合、保留冷却的四组对照、固定事件前状态的能力验证及恢复审核。它们回应了原评审的问题，原评审中的“当前代码观察”属于修订前状态。没有作者数据/代码，不能称为该论文数值复现；本轮也不继续实现其混合范数DRO或新增参考求解器。

课题的核心贡献应放在：架构限制下可达的电池能力如何被业务保障、备用与恢复条件限制，以及协同调度如何改变这一能力。不要把算法数量、功能数量或原论文百分比作为本项目贡献。

## 2. 先定义可比较的研究量

- **电池独立闲置能力**：固定参考IT、冷却、作业进度与事件前状态，在给定故障及恢复条件下的恒定进口削减功率—持续时间；这里的“可用”是模型条件下有可行见证，不是铭牌剩余电量。
- **站点联合能力**：允许业务和热状态按同一合同调整后的进口削减能力；其中含负荷重排和冷却柔性，不全是电化学储能。
- **协同增量**：同一参考、事件、持续时间和保障集合下二者的差。不能把电池能力和各负荷独立最大值直接相加。

架构比较固定完整IT/冷却/作业历史，同时声明装机资产是否相同。业务类型比较必须依赖实际合同窗口、检查点、延迟及完成量，而不是只换业务名称。恢复用电、补能和服务缺额要与事件能力一并报告。

## 3. 现有封存实验支持什么

使用既有主实验`runs/thesis_20261111_005814_330365`与匹配参考实验`runs/matched_20261111_013313_597650`，本轮重新核对两份SEAL及所有被封存文件，继续满足33139及5813项既有轨迹检查。未由`results/`中可能被覆盖的最新结果推导新结论。精简来源SHA及重算统计见[分析证据](paper_analysis_evidence.json)。

### 相同参考下的能力

| 架构 | 电池独立MW，1h | 电池独立MW，2h | 联合MW，1h/2h |
|---|---:|---:|---:|
| N | 0.00000 | 0.00000 | 7.21999 |
| N+1 | 0.54149 | 0.27074 | 7.21999 |
| 2N+1 | 2.97824 | 1.48911 | 7.21999 |
| 2(N+1) | 3.44590 | 1.72294 | 7.21999 |

该情景中电池能力随备用资产与路径配置变化，2小时恒定功率约为1小时的一半，符合能量限制的表现。联合能力则达到共同参考进口约7.22 MW的上限，存在上界截断；不能因此声称架构对联合能力没有影响。N电池独立能力为0而联合能力为正，尤其说明联合MW不是可直接交易的电池闲置MW。

比较同时改变了资产数量，不能将此表解释为“相同MWh下纯拓扑作用”，也不能用各架构自行优化参考的另一张表直接给硬件排名。既有模型反例支持共享备用不能跨路径重复出力；它不是现场共享备机接线及切换性能的证明。

### 公平四组对照与交互

令`I=(C顺序调频−C联合调频)−(C顺序无调频−C联合无调频)`，正值表示给定情景下，联合优化的成本优势在调频启用后增大。它是模型政策对照，不是随机试验的因果估计。

| 架构 | 交互I，元/代表日 | 最终联合调频相对顺序无调频的成本下降 |
|---|---:|---:|
| N | 58.99 | 0.736% |
| N+1 | -40.37 | 1.439% |
| 2N+1 | 671.78 | 5.898% |
| 2(N+1) | 717.53 | 6.611% |

N+1提供了直接反例：联合调频仍降低净成本，但“耦合×调频”交互并非总为正。用求解器上下界传播得到的I区间约[-40.36866,-40.32434]元，仍为负；这不是数值零点误差。上述区间是**求解界，不是统计置信区间**。本研究只有一个历史价格/代表日，不能推出所有站点、季节或当前市场的收益规律。不同架构资产投资未由该运行成本表完整比较，不能据其评选最优投资方案。

保留主实验96个给定失电情景中的24个失供，以及48个设计负荷检查中的16个不满足。它们约束研究结论，不能为使架构“看起来合规”删除失败。条件失电回放及样本EENS也不能直接变成年故障率、年EENS或Tier等级。

## 4. 外部实测如何改变论文可信度

[校准报告](../calibration/实测校准报告.md)新增三类独立观测，分别服务于不同研究量，没有把它们拼成虚构的同一站点：

1. Azure连续7天约1680万条生产请求支持非平稳到达形状和token异质性；2023旧样本只有约一小时，不足以声称全天负载规律。到达数据本身不识别功率、服务率或时延合同。
2. HUST两颗LFP电芯支持外部容量/能量先验，并揭示单直线退化的迁移误差；同电芯末期留出RMSE约7.57个百分点，不应据训练拟合就冻结为现场寿命规律。最初10循环用于各电芯归一，跨电芯评价需要这项初始测量，不是完全零样本预测。
3. MLPerf锚点支持特定B200系统的吞吐、平均功耗和分项延迟；TTFT、TPOT和完整响应不同。一个功耗—吞吐点不能同时识别待机与边际能耗，也不能给Azure请求直接配上该硬件功率。

冻结退化输入的命名参数集存在NMC/LFP溯源缺口，真实训练检查点、GPU服务性能和作业截止仍无现场校准。外部数据增强了机制假设的边界认识，**尚未使已封存的合成合同实验变成真实业务实证**。本轮没有将新参数写回原实验，故不能声称原经济表已经在公开数据上重新实证。

## 5. 论文主张与取证清单

| 拟表述 | 当前判定 | 需要保留的条件/补证 |
|---|---|---|
| 模块/路径、服务与恢复共同限制闲置能力 | 机制层可支持 | 合成合同、静态转供、给定故障与参考状态 |
| 算电协同可以增加站点可调能力 | 给定情景可支持 | 与电池能力分别报告，声明上界截断及恢复代价 |
| 调频必然增强协同价值 | 当前反例不支持 | 报告负交互，不删N+1结果 |
| 已得到适用于真实IDC/AIDC的LFP寿命和GPU SLA | 不支持 | 现场化学体系/工况、能效曲线、延迟测量与真实合同 |
| N、N+1、2N+1、2(N+1)直接对应Tier | 不支持 | 完整设计、维护性/容错及第三方审核 |
| 符合用户全部11项规范 | BLOCKED | 正式版次/条款、适用性及独立工程证据，见规范补充 |
| 现有运行成本最低的架构就是经济最优架构 | 不支持 | 不同装机资产、投资成本与全年价格/寿命风险 |

下一阶段的最小取证范围固定为：一个可匿名化站点的单线图及接口/分组、可时间对齐的电表/BMS观测、四类业务的真实服务合同和执行观测、正式采用的规范及已有工程试验。拿到哪一类证据，只更新对应校准/论文论证；拿不到时明确研究情景与限制。**不再引入新算法、新页面或新模型模块作为“验收前置条件”。**
