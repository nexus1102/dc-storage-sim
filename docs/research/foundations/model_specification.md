# 架构、服务约束与闲置能力的形式化定义

实现入口：sim/physical_topology.py、service_contracts.py、capability.py；共享运行内核仍是dispatch.py。旧V3默认入口与基线保留；显式传入physical_topology/service_contracts才启用新模型。运行研究实验：`python sim/foundation_experiments.py --slots 24`。

## 1. 既有架构是固定图，不是待配置的模块总数

固定资产集合包括UPS单元i、供电路径p和负载组g。每个单元具有能量E_i、功率P_i和SOH_i；边集合描述单元能连接的路径和负载组可接受的供电路径。路径有额定功率。**单元SOC分别递推，不能先汇总后任意跨路使用。**

| 名称 | 当前研究约定 | 故障含义 |
|---|---|---|
| N | 一路N个单元 | 满设计负荷下失去一个单元会短缺；实际轻载时可能仍能供电 |
| N+1 | 同一路N个工作单元及一个冗余单元 | 容量冗余不保护共同路径故障 |
| 2N+1 | 两路各N个单元，另一个可在两路间切换的共享备用 | 共享备用同一状态只能接入一路，禁止重复计算 |
| 2(N+1) | 两路各自N+1个单元 | 两个备用分别属于各自路径，不任意跨路池化 |

默认N=5，每单元0.5MWh/2MW，是研究情景；API允许不同能量、功率、SOH、连接边、路径额定和单/双路负载组。不能只凭架构名称推断现场电气图。双向接口及静态切换必须具备，未模拟毫秒级转供中断、保护配合、共因故障或BMS通信。

当前负载组采用固定电气份额，业务合同先汇总为站点功率再分配；尚未将每个作业放置到具体机架或UPS节点。多节点作业迁移若要与本模型联合，必须进一步提供任务到电气负载组的映射，不能直接套用旧迁移结果。

每个故障s删除相应单元或路径，故障后电量沿幸存边流动：

\[
\sum_p f_{ips}\le\min\{\eta E_i SOC_i-r^{up}_iT_{reg},\ P_iT_{ride}\},
\qquad \sum_i f_{ips}\le P_pT_{ride}.
\]

代码SOC_i直接使用MWh，所以上式第一项实现为eta*soc_i，避免再次乘E_i。路径入流=出流，各组收到的电量不小于其关键负荷需求。共享备用的路由使用0/1变量和至多接一路约束。正常充放电及调频同样接受单元和路径额定约束；为避免复杂交流潮流，正常路径双向裕度用保守的绝对功率和限制。

故障持续需求采用后续穿越窗口内站点负荷最大值乘穿越时长。对该负荷上界是充分保障；对时变负荷是**保守内近似**，不声称精确多时段故障轨迹或概率可靠性。默认运行保障“失电+任意一单元故障”；整路失效另行审核。对N/N+1强行要求整路失效后仍供电应当不可行，不能悄悄放松。

## 2. 业务交付量与耗电量分开

任务j有到达r_j、截止d_j、有用工作W_j及功率上下界。工作量采用等效满载MWh作为代理单位，不能当成已经标定的token或训练step：

\[
\sum_{t=r_j}^{d_j-1}x_{jt}\Delta t+u_j=W_j.
\]

可交付任务默认u_j=0，严格截止；批处理允许显式有价缺额u_j时，费用进入同一目标并输出，不能事后补计。可配置硬/软截止，避免用业务名称替代实际合同。

训练有运行状态z_jt、启动/恢复状态a_jt，a=max(0,z_t-z_{t-1})，并要求每次启动后最少连续运行若干时隙，代表最短可检查点执行段。它不是精确GPU/并行训练执行器，也未建模不可恢复的历史计算丢失。电表功率：

\[
P^{train}_{jt}=x_{jt}+E^{restart}_j a_{jt}/\Delta t.
\]

有用工作不会因重启而虚增，额外恢复电量必须付费。开始日首次启动也收该情景定义的启动费用。

推理采用**稳态M/M/1代理**：每时隙到达率lambda、服务率mu，响应时间尾概率为exp[-(mu-lambda)D]，因此：

\[
\mu_t\ge\lambda_t+\log(1/\epsilon)/D,
\quad P^{infer}_t=P_{idle}+J_{request}\mu_t/10^6.
\]

这是可检查的解析服务裕度，不是对真实LLM推理的分布保证；批量、prefill/decode、GPU显存和长尾服务时间尚未纳入。15分钟或1小时电力采样不等于秒级延迟仿真。到达率、单位请求耗能、响应阈值和违约率均须实测替换。

## 3. 闲置能力是完整可行域的投影

令F(a,s,x_0,J)包含固定架构、故障约束、单元SOC、业务交付、热平衡、功率和日末恢复条件。针对已保存的可行参考轨迹G_ref及事件区间I，定义：

\[
P^*(I)=\max\ P\quad\text{s.t.}\quad (x,u)\in F,
\quad G_t\le G^{ref}_t-P\ (t\in I),\ P\ge0.
\]

事件前已经执行的功率、热状态、逐单元SOC、训练开停与各作业工作进度固定为参考；事件后的恢复仍受电网/设备容量及截止约束。软截止缺额不得比参考增加。因此不能从自由初始能量、提前知晓事件的作业调整或额外违约中凭空获得能力。

默认参考模式为standby：电池没有日常充放电，逐单元SOC固定为配置上限，表示明示的“仅备电”情景初态。可用`--reference economic`选择已经参与电费优化的参考；两者对应不同问题，不应混合比较。design_load用于满设计负荷审核基准，不自动推断现场IT额定、分级负荷或Tier认证；实际供电约束仍由单元、路径和负载组接线决定。

输出持续时间D=|I|dt、功率P*、交付电量P*D、求解上下界、可行见证与增量成本。该电量是电网侧减少进口电量，可能同时包含业务调整与电池贡献，**不能直接命名为电池闲置MWh**。

能力边界先最大化功率，再在边界内最小化成本。为避免MILP数值容差使第二次求解落在边界外，当前实现为可行见证留出max(1e-5MW,边界功率×1e-6)的内缩裕度，并在输出中保留witness_margin_mw和原对偶上界。较早封存算例的裕度取值以其冻结源码为准。

- battery_only：固定参考IT和冷却轨迹，计电池侧可用能力。
- joint：允许同合同内重排，计算电协同能力；减去battery_only才是协同增量。

两者固定相同初始状态、事件和保障范围；功率-持续时间结果不是装机能量减一条备用常数。因存在离散开关和训练状态，可行域一般是混合整数投影；只对给定事件方向求认证边界，不声称已画出全部非凸集合。

## 5. 当前实现范围

新物理模型采用逐单元循环日状态；尚不接受旧聚合MPC的initial/terminal状态。传入不兼容的状态会明确报错，不能把旧MPC验收结果用于声称新拓扑已实现实时执行。继续扩展MPC时必须携带每个单元SOC、当前开关状态和作业进度。共享备用的理想无时延切换和M/M/1假设也不构成现场可靠性/SLA认证。
